# 流程与状态

## 建议目录

在用户指定的项目目录下保存运行产物，不把账号数据写进 Skill 本体。

```text
project/
  account.md
  direction-decision.md
  benchmarks/
  topic-queue.md
  assets/
  posts/
    YYYY-MM-DD-slug/
      title.txt
      body.txt
      images/
      preview.html
      internal-record.md
      metrics.md
```

## 状态机

`方向待选 -> 方向已定 -> 样本已建 -> 选题待制作 -> 待补素材 -> 待审阅 -> 已批准 -> 已发表 -> 已观察 -> 已复盘`

状态只能由可见证据推进：

- 用户说出选择，才能进入“方向已定”。
- 最终图片与正文齐全，才能进入“待审阅”。
- 用户确认具体成品，才能进入“已批准”。
- 平台回读显示已发表，才能进入“已发表”。
- 记录真实时间和指标，才能进入“已观察”。

## 每阶段输出

| 阶段 | 必要输出 |
| --- | --- |
| 方向选择 | 三个候选或用户已有方向、选择依据、停止条件 |
| 对标研究 | 样本表、已打开范围、不可访问项、可借结构 |
| 首轮计划 | 7—14 个题目、所需素材、依据、测试变量 |
| 单篇制作 | 标题、正文、图片顺序、内部来源、预览、缺项 |
| 发布 | 目标账号、用户批准记录、平台状态、时间、内容标识 |
| 复盘 | 观察窗口、真实指标、判断边界、下一项改动 |

## 自动化边界

方向候选、网页研究、样本拆解、选题、素材候选、文案、预览、检查和复盘可以由智能体执行。最终方向、对外内容审阅、实名扫码、协议接受由本人处理。平台工具不可用时，交付完整的发布包和清楚的手动步骤，不宣称已发表。
