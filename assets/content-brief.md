# 单篇需求与页面计划

这是制作前使用的内部模板。已有明确选题时直接填写；不需要重新选择账号方向。完成后随作品保存，不复制到读者正文。

## 读者要解决什么

- 选题：
- 给谁：
- 发生在什么时刻：
- 读者正在犹豫或卡住的事：
- 看完能带走的判断、动作、清单或选择：
- 本篇不承诺的结果：

## 材料是否支持交付

- 必须在照片中看见的主体、状态或动作：
- 已有材料及文件：
- 尚缺的画面：
- 必须核验的事实、数量或价格：
- 有关本人经历的表述及真实依据（没有就不写）：

## 标题与封面一起选

列出少量确实不同的角度，例如购买选择、操作卡点、状态判断或结果展示；有必要时再扩展候选。不要用不同形容词伪装成不同角度。

| 候选标题 | 谁在什么时刻会点 | 实际交付什么 | 哪页兑现承诺 | 未证实的承诺或需要修改处 |
| --- | --- | --- | --- | --- |
| | | | | |

- 采用的标题：
- 封面主句及画面：
- 与相邻作品的题目、句型和交付差异：
- 图片下短文补充的信息（避免把图片再念一遍）：
- 需要向读者问的具体问题（无必要可留空）：

## 转入成稿前

- 关键材料未齐：继续补图，或重新评估承诺；不靠弱化成品价值保住现有图片。
- 材料齐全：制作最终图片、标题、正文与手机预览，再用 [post-record.md](post-record.md) 记录实际文件和状态。
